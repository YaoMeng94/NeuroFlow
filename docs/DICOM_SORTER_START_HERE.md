# NeuroFlow DICOM Sorter

Version **0.4.22** is the current internal prototype. The standalone app sorts copied scanner DICOM files into one folder per subject and series, and optionally converts sorted data to BIDS. Sorting does not depend on BIDS conversion. The scanner export is preserved.

## Version 0.4.22 Mac test package

The current Apple Silicon package is in `dist/standalone_sorter/`:

- `NeuroFlowDICOMSorter-macOS-arm64-0.4.22.zip`
- Matching `.sha256` checksum file

Unzip the archive, move `NeuroFlowDICOMSorter.app` to Applications, and open it. The internal academic build may not be notarized; if macOS blocks first launch, use Finder’s Control-click → **Open**. Confirm the app title shows **v0.4.22**.

The Windows installer is generated by the `build-dicom-sorter` GitHub Actions workflow for version 0.4.22. It will be named `NeuroFlowDICOMSorter-Windows-Setup-0.4.22.exe` and will include its checksum. Confirm **v0.4.22** in the app title after installation. Build artifacts are attached to the workflow run, not published as a public release.

No Python, dcm2bids, or dcm2niix installation is needed for the packaged apps. NeuroFlow’s processing pipeline and neuroimaging containers are separate products.

## Sort DICOM files

1. Select the scanner export folder. The app suggests a separate `_sorted` output folder.
2. Click **2 · Preview sequences** and review the subject IDs, descriptions, protocols, categories, and statuses. IDs come from DICOM `PatientID`; the app does not generate sequential participant numbers.
3. Review any unmatched or ambiguous sequences. The general preset covers common MRI sequence naming and routes `PhysioLog` / PMU recordings to `physio`. Open **Advanced: change sequence rules** to use the Prisma preset or edit a JSON mapping.
4. Click **3 · Copy to sorted folder**. Original scanner files remain unchanged.

Example layout:

```text
scanner-export_sorted/
  sub-20261016001/
    anat/series-6_3dT1w_mpr_sag_1mm/
    dwi/
    func/
    physio/
    _unmatched/
```

## Optional BIDS conversion

1. Sort and review the DICOM files first.
2. Choose one detected `sub-…` participant or **All subjects**.
3. Choose a new or empty BIDS output folder and review the included dcm2bids config.
4. Optionally enter a session label, then click **Convert to BIDS…**.

The app converts participants one at a time and includes dcm2bids and dcm2niix. Inspect NIfTI images and JSON sidecars, confirm the intended normalized structural series and acquisition metadata, then run a BIDS validator before preprocessing.

This prototype is for internal academic use. Store participant data according to institutional data-handling rules.
